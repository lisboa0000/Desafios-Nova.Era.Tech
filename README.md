This repository documents my progress throughout the **Nova Era Tech Backend JavaScript Formation**.

### ✅ Challenge 07 — Social Network (MongoDB)

**Reward:** +500 XP

REST API for a mini social network with users, posts, and comments, exploring MongoDB data modeling and aggregations.

**Technologies & Concepts**
- MongoDB and the official Node.js driver
- Embedded vs. referenced modeling (comments embedded, author referenced)
- Aggregation Pipeline (`$lookup`, `$sort`, `$group`)
- Array operators (`$push`, `$addToSet`, `$slice`)
- Indexes validated with `explain` (IXSCAN)
- Feed ordered by date with hashtag filter, likes, and top hashtags

**Status:** `Completed`

---

### ✅ Challenge 08 — Complete REST API

**Reward:** +500 XP

Courses management API consolidating everything learned so far: authentication, permissions, pagination, filters, and standardized errors.

**Technologies & Concepts**
- Node.js, Express, and SQLite
- JWT authentication and role-based guards
- Pagination and filters
- Zod validation and standardized error format
- OpenAPI/Swagger documentation and API versioning (`/api/v1`)

**Status:** `Completed`

---

### ✅ Challenge 09 — Docker Compose

**Reward:** +500 XP

Multi-service environment (API + MongoDB + Mongo Express) started with a single command.

**Technologies & Concepts**
- Docker Compose, networks, and volumes
- Environment variables and `.env` (no hardcoded credentials)
- Healthchecks and `depends_on` with `service_healthy`
- Compose profiles (`tools`, `test`)
- Data persistence across container restarts

**Status:** `Completed`
